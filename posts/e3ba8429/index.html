Windows 定时任务（怎么开机就执行 Bat 文件）

方法一：将脚本放入「启动」文件夹

特点：简单快捷，但需用户登录后执行。

​​步骤​​：

  1. 打开启动文件夹：
    • 按 Win + R，输入 shell:startup 回车
  2. 创建脚本快捷方式：
    • 将你的 .bat 文件复制到该文件夹，或右键选择「新建快捷方式」。
    • 若需管理员权限，右键快捷方式 → 属性 → 高级 → 勾选 用管理员身份运行。

方法二：通过任务计划程序（目前使用）

特点：可设置开机自动执行（无需登录）、管理员权限、后台静默运行。

​​步骤​​：

  1. 打开任务计划程序：
    • 按 Win + R，输入 taskschd.msc 回车。
  2. 创建新任务：
    • 右侧点击 创建任务 → 输入名称（如 AutoRun BAT）。
  3. 设置触发器：
    • 新建 → 选择 登录时 或 启动时（启动时需管理员权限）。
  4. 设置操作：
    • 新建 → 操作选择 启动程序 → 浏览选择你的 .bat 文件。
    • 若需隐藏窗口：添加参数 cmd /c "你的脚本.bat"，并在 起始于 填写脚本所在目录。
  5. 配置权限：
    • 常规 → 勾选 不管用户是否登录都要运行 和 使用最高权限。
  6. 保存任务 → 重启测试。

方法三：修改注册表

特点：直接写入系统启动项，但需谨慎操作。

​​步骤​​：

  1. 按 Win + R，输入 regedit 回车。

  2. 导航到注册表路径：HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Run

  3. 新建字符串值：

    • 右键空白处 → 新建 → 字符串值 → 名称自定义（如 AutoRunBAT）。
    • 双击该值，在 数值数据 中填写脚本绝对路径（如 "C:\Scripts\your_script.bat"）。

  4. 重启生效。

方法四：组策略编辑器（专业版/企业版）

特点：适合企业环境集中管理。

​​步骤​​：

  1. 按 Win + R，输入 gpedit.msc 回车。
  2. 导航到路径：计算机配置 → Windows 设置 → 脚本（启动/关机）
  3. 双击「启动」 → 添加 → 浏览选择你的 .bat 文件。
  4. 重启生效。
