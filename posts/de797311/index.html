性能测试展望

发表于2025-07-19|更新于2026-10-17|软件测试
|总字数:256|阅读时长:1分钟|浏览量:

初级性能测试工程师

  • 按露求及测试方案编写对应脚本并执行
  • 熟悉一种性能厕试工具，如 jMeter
  • 有一定代码基础，便于编写测试脚本
  • 熟悉被测业务

中级性能测试工程师

  • 制定测试策略，监控策略
  • 熟悉性能理论知识，熟悉性能测试流程
  • 针对性能需求可以制定对应的测试策略
  • 熟悉 linux 基本命令，可以通过基本命令进行服务监控
  • 熟悉 Prometheus，Zabbix、InfluxDB 等至少一种监控工具

高级性能测试工程师

  • 具体问题定健能力、调优能力
  • 熟悉 JVM 基本知识
  • 熟悉 Tomcat 和 WebLogic 等中间件知识
  • 熟悉数据库知识，可以对数据库相关提出淘汰，改进建议
  • 深入了解 Linux 命令，可以通过命令监控找到对应瓶颈点
  • 熟悉 Java 代号，可以通过线程栈、堆 dump 分折代码层，并给出改进建议
