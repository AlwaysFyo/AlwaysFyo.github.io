1.2 八类基本元素定位方式

在做 WEB UI 自动化时，最根本的就是操作页面上的元素，首先我们要能定位到这些元素，然后才能操作这些元素。

定位方法：driver.find_element(By.XXX, "YYY")

注意： 并不是每个页面的元素都需要用到下面的八种方法，比如一些页面的元素就是没有 id，则就不能用 id 进行定位。

元素名称 By.XXX
id By.ID
name By.NAME
class name By.CLASS_NAME
tag name By.TAG_NAME
link text By.LINK_TEXT
partial link text By.PARTIAL_LINK_TEXT
xpath By.XPATH
css selector By.CSS_SELECTOR

1.2.5 通过 Link Text 定位

Link Text 和 Partail Link Text 都是用于定位超链接元素，例如百度左上角这些元素，点击后会跳转到另一个页面。

1.2.6 通过 Partial Link Text 定位

Partial Link Text 和 Link Text 的区别是可以模糊匹配超链接文本，例如有些超链接文本太长，我可以只输入一部分文字进行匹配，就能定位到对应的元素。

1.2.7 通过 Xpath 定位

对于实际场景中，很多元素没办法通过前面的六种简单的方式定位，就需要通过后面两种方式来进行定位，先来看 Xpath 是怎么定位的：

  • 绝对路径：以 / 开头定位，例如 `/html/body/input/xx
  • 相对路径：以 // 开头定位，例如 //input[@id='kw' and @name='wd]

1.2.8 通过 CSS Selector 定位

通过 CSS Selector 整体功能和 Xpath 类似，只是 CSS 定位的语法不同，常用语法如下：

  • 以 ID 定位：#id
  • 以 Class Name 定位：.class
  • 以 Tag Name 定位：tag
  • 以 Tag Name 下的某个 ID 定位：tag#id
  • 以 Tag Name 下的某个 Class Name 定位：tag.class
  • 通过其它属性定位：[属性名=属性值]

1.3 复数定位元素方式

定位方法：driver.find_elements(By.XXX, "YYY")

find_elements 属于 selenium 中复数的定位元素内容，find_elements 主要定位页面上多个相同的元素。

例如，我现在想定位百度页面左上角一列的超链接按钮。

而定位的方法其实和上面的 find_element 定位方式一模一样，只是这里的方法名后面多了一个 s，所以我们现在只用找到这些相同元素下相同的属性值用来定位。

1.4 元素定位策略

推荐的定位方式的优先级：ID > name > CSS selector > Xpath

定位元素的注意事项：

  • 找到待定位元素的唯一属性
  • 如果该元素没有唯一属性，则先找到能被唯一定位到的父元素/子元素/相邻元素进行辅助定位
  • 不要使用随机唯一属性定位
  • 最重要的是多跟研发沟通，尽量把关键元素加上 ID 或者 name，并减少不合理的页面元素，例如重复 ID 这样的事情最好不要发生

2. Selenium 操作

2.1 元素的操作

在自动化测试中，成功定位到元素后，即可对元素进行相应的操作。

webdriver 中比较常用的操作对象的方法如下：

方法名称 功能
click() 点击对象
send_keys() 在对象上模拟键盘输入
clear() 清楚对象内容
submit() 表单提交，可以触发 action 行为
text 用于获取对象的文本信息
size 用于获取元素尺寸
get_attribute() 获取元素属性
is_displayed() 元素是否可见

2.2 浏览器的操作

在自动化测试中，除了可以对元素进行操作外，同样也支持对浏览器进行控制。

webdriver 中比较常用的操作浏览器的方法：

方法名称 功能
maximize_window 浏览器最大化
set_window_size 设置浏览器的宽和高
back 后退
forward 前进
refresh 刷新
title 打印 title
current_url 打印 url

2.3 键盘按键用法

在 Selenium 自动化测试中，要调用键盘按键操作需要引入 keys 包，并通过 send_keys() 调用按键。

Keys() 类提供了键盘上几乎所有按键的方法，这个类可以用来模拟键盘上的按键，包括各种组合键，如 Ctrl+A、Ctrl+X、Ctrl+C、Crtl+V 等等。

属性 含义
Keys.DOWN, Keys.UP, Keys.LEFT, Keys.RIGHT 键盘箭头键
Keys..ENTER, Keys.RETURN 回车和换行键
Keys.HOME, Keys.END, Keys.PAGE_DOWN, Keys.PAGE_UP Home 键、End 键、Page Up 键、Page Down 键
Keys.ESCAPE, Keys.BACK_SPACE, Keys.DELETE Esc、Backspace 和删除键
Keys.F1, Keys.F2, …, Keys.F12 键盘顶部的 F1 到 F12
Keys.TAB Tab 键

2.5 多框架切换定位用法

在 Web 应用里经常会出现框架或窗口的应用，有时候定位一个元素，定位器没有问题，但是却一直定位不了，这个时候就要检查这个元素是否在一个 frame 中，switch_to.frame() 是将当前定位的主题切换到了 frame 里。因为 frame 中其实相当于嵌入了另一个页面，webdriver 每次只能在一个页面识别。

2.6 多窗口切换定位用法

在页面操作过程中有时候点击某个链接会弹出新的窗口，这时就需要主机切换到新打开的窗口上进行操作。WebDriver 提供了 switch_to.window() 方法，可以实现在不同的窗口之间切换。
