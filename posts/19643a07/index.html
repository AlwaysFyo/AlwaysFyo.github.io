Grafana

Grafana 简介

官网： Grafana: The open observability platform | Grafana Labs

作用： 数据分析展示

Grafana 安装

  • 下载 Grafana 镜像, 并运行容器

    • idt: 是 docker run 命令的选项
      • i 表示保持标准输入（STDIN）打开，使容器的标准输入保持可用
      • d 表示 容器在后台运行（分离模式）
      • t 表示在容器中分配一个伪终端（pseudo-TTY），以便可以与容器进行交互

  • Grafana web 访问： http://192.168.75.131:3000 (/)
